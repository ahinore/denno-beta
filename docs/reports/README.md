# Task reports / タスクの報告

`REPORT_P<N>.md` is the report of development task N, written by the agent that did it: what was tried, the lab measurements, and the first line `ADOPT: yes` or `ADOPT: no`. Code comments cite them by name (for example `REPORT_P242`). The story they add up to is in [docs/history](../history/).

`REPORT_P<N>.md` は開発タスク N の報告で、担当したエージェントが書いた。試したこと、lab の計測値、1 行目の `ADOPT: yes` / `ADOPT: no`（採否）が入っている。コードのコメントは名前で引く（例 `REPORT_P242`）。全体の流れは [docs/history](../history/) にまとめてある。

Reports are written at the repository root while a task runs and moved here when main is updated. 作業中はリポジトリの直下に書かれ、main を更新するときにここへ移す。
