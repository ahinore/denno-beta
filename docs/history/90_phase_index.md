> [索引](README.md) / 前: [第8巻 計測・検証・運用](70_infra.md)
この文書は**機械的に作った索引**。各巻の `## 対象 phase 一覧` の表を突き合わせて、
日付順に並べ直したもの（129 phase）。**内容の正は各巻の本文**で、ここは「いつ・どの commit で・
どの巻に書いてあるか」を引くための表。
- 同じ phase が 2 巻に出ることがある（例: P11 はストリーミングの修正が API と decode の両方に効いた）。
  その場合は両方の行を残してある。重複ではなく、別角度の記述。
- commit の SHA は短縮形。日付は作者日付（author date）。
- 数値はここには書かない。数値は各巻の本文と `docs/KPI.md` にある。
