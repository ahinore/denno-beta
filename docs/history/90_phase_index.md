> [索引](README.md) / 前: [第8巻 計測・検証・運用](70_infra.md)

この文書は**機械的に作った索引**。各巻の `## 対象 phase 一覧` の表を突き合わせて、
日付順に並べ直したもの（137 行）。**内容の正は各巻の本文**で、ここは
「いつ・どの commit で・どの巻に書いてあるか」を引くための表。

- 同じ phase が 2 巻に出ることがある（P11 は API と decode、s53c は API の受理形式と品質の切り分け）。
  重複ではなく、別角度の記述なので両方の行を残してある。
- 日付は commit の author date。前身リポジトリの commit（第4巻の P8〜P12）はこのリポジトリに存在しない。
- 数値はここには書かない。数値は各巻の本文と `docs/KPI.md` にある。
